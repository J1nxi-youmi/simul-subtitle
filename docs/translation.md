# 翻译

翻译使用 B 站开源的 **[Index-Translate](https://github.com/bilibili/Index-Translate)**。

## 两种方式

| | 在线翻译（默认） | 手机上翻译 |
|---|---|---|
| 模型 | Index-Translate-35B-A3B（默认）/ 9B / 2B | Index-Translate-2B Q4_K_M（llama.cpp，CPU 4 线程） |
| 地址 | B 站开放的免费接口 `index-translate.bilibili.com`，不需要 key | 本机 |
| 需要下载 | 无 | 约 1.3 GB |
| 断网时 | 这句显示「翻译失败」，不会自动换成本地 | 正常 |
| 速度 | 快 | 慢很多，句子密时会积压 |

在线方式发送的只有识别出的文字和提示词，不发送声音。

## 提示词

格式与 Index-Translate 官方推理代码一致（`inference/llm/translate.py`）：

- 没有约束时：`请将以下{原文语言}文本翻译为{目标语言}，直接输出翻译结果，不要进行任何解释。`
- 有约束时：`【源文】` + `【约束要求】`，约束包括：
  - **术语对照**（硬性要求）：当前场景的术语表里在这句出现的词，只在译成中文时使用；
  - **场景背景**（注意）：例如「B站 VTuber 直播」场景会说明这是 B 站直播闲聊、原文来自语音识别；
  - **前文**（注意）：最近说完的几句原文，只用于理解指代和省略，不翻译；
  - **修正提示**（注意）：Jev 检查出问题后重译时附带的说明（见 [jev.md](jev.md)）。
- 原文语言选「不确定」时，提示词里不写原文语言，由模型自己判断。
- 贪心解码、不加重复惩罚；一句输出上限：中文 160 token，其他语言 256 token（本地模型上下文 2048）。

## 结合上文

设置里的「结合上文来翻译」默认开启、参考 2 句，可以调成 1–5 句或关闭，从下次开始字幕时生效。

- 上下文是最近几句**非空定稿**的原文。
- 一个段落的上下文在它前一句定稿翻译完后固定下来，所以同一段的草稿、定稿和重译用的是同一份提示词，复用缓存继续有效。
- 句数越多，每次翻译要处理的文字越多，速度越慢。

## 场景

| 场景 | 背景说明 | 术语表 |
|---|---|---|
| 通用 | 无 | 无 |
| B站 VTuber 直播 | B 站直播闲聊、念弹幕和 SC、原文是语音识别结果 | ビリビリ→B站、スパチャ→SC、配信→直播 等 |

## 支持的语言

- **原文**：日语、英语、不确定（日语或英语）。受语音识别模型限制。
- **译文**：Index-Translate 的 22 种核心语言：中文、英语、日语、韩语、德语、法语、西班牙语、葡萄牙语、俄语、阿拉伯语、意大利语、荷兰语、波兰语、罗马尼亚语、瑞典语、土耳其语、印地语、越南语、泰语、印尼语、马来语、菲律宾语。
- 日译中以外的语言对没有专门调过提示词和输出长度。
