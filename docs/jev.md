# AI 辅助（Jev）

[Jev](https://typesafe.ai) 是 TypeSafe 的云端判断模型：它不生成文字，只回答带概率的结构化问题。App 用它做两件可选的事，都默认关闭，彼此独立。

## 智能断句

问题：“这段话说完了吗？”

- 开启后，Segmenter 在每个可能的句尾（0.4 s 停顿，或一段达到 5 s）先发出一份草稿去问 Jev，最多等 1 s。
- 5 s 时被判断为没说完，这段会继续，最长到 10 s 才强制切开。
- Jev 认为没说完时，这句先不定稿，等说话人继续；回答超时或出错时，按没开 Jev 处理。

## 检查译文

问题：“这句译文有没有把意思译错？”分类包括凭空加入否定、把肯定/否定或转折译反、把比喻或直播用语按字面直译等。

- 每句定稿翻译完后检查一次；置信度达到 0.6 且属于可修正的类别时，附上对应说明重新翻译这一句。
- 打开后每句定稿会晚一点出现。

## 服务

| 服务 | key |
|---|---|
| OpenCode Zen（默认） | 不需要；免费的公共接口，可能随时限速或停用 |
| TypeSafe 官方 | 需要 |
| OpenRouter | 需要 |

- 只发送识别出的原文和译文，不发送声音。
- key 用 Android Keystore 加密保存在本机，不写进使用记录。
- 任何失败都保留本地结果，字幕照常显示。
