# 在线 Decisions 模型辅助（Jev）

[Jev](https://typesafe.ai) 是 TypeSafe 的云端判断模型：它不生成文字，只回答带概率的结构化问题。App 用它做两件可选的事，都默认关闭，彼此独立。

> Jev **不是开源项目**，是 TypeSafe 的闭源商业云服务。App 只是通过网络调用它的接口；关掉这两个开关时，App 不会发出任何 Jev 请求。

## 智能断句

问题：“这段话说完了吗？”

- 开启后，Segmenter 在每个可能的句尾（0.4 s 停顿，或一段达到 5 s）先发出一份草稿去问 Jev，最多等 1 s。
- 5 s 时被判断为没说完，这段会继续，最长到 10 s 才强制切开。
- Jev 认为没说完时，这句先不定稿，等说话人继续；回答超时或出错时，按没开 Jev 处理。

## 检查译文

问题：“这句译文有没有把意思译错？”分类包括凭空加入否定、把肯定/否定或转折译反、把比喻或直播用语按字面直译等。

- 每句定稿翻译完后检查一次；置信度达到 0.6 且属于可修正的类别时，附上对应说明重新翻译这一句。
- 打开后每句定稿会晚一点出现。

## 服务

| 服务 | key |
|---|---|
| OpenCode Zen（默认） | 不需要；免费的公共接口，可能随时限速或停用 |
| TypeSafe 官方 | 需要 |
| OpenRouter | 需要 |

- 只发送识别出的原文和译文，不发送声音。
- key 在手机上用 Android Keystore 加密保存，在 Mac 上存在钥匙串里，在 Windows 上用 DPAPI 加密保存；都不写进使用记录。
- 任何失败都按没有 Jev 时的做法处理（断句照常按停顿，译文照常显示），字幕不受影响。

## 请求频率与费用

### 什么时候发请求

| 功能 | 每次请求的时机 | 频率取决于 |
|---|---|---|
| 智能断句 | 每个可能的句尾：0.4 s 停顿，或一段说到 5 s | 说话人的停顿次数，比字幕句数多 |
| 检查译文 | 每句定稿翻译完后一次（重译后不再检查） | 定稿句数 |

两个都开时，请求数相加；每个请求只问一个问题。

### 实测数据

数据来自一次 61.8 分钟的日语 VTuber 直播使用记录（两个功能都开，TypeSafe 官方接口），用量取自接口返回的 `usage` 字段：

| 功能 | 请求数 | 每分钟 | 平均输入 token | 平均输出 token |
|---|---|---|---|---|
| 智能断句 | 1031 | 16.7 | 603 | 20 |
| 检查译文 | 451 | 7.3 | 595 | 85 |
| 合计 | 1482 | 24.0 | | |

输入 token 大部分是固定的问题说明，每句原文 / 译文只占一小部分，所以每次请求的 token 数比较稳定（实测最少 540、最多 737）。

### 费用

Jev 按输入 token 计费：**每百万输入 token 0.042 美元，输出不计费**（价格来源：[TypeSafe 发布文章](https://typesafe.ai/blog/introducing-system-one-models-and-jev)，以及 OpenRouter 上 `typesafe/jev-1.13` 的标价）。

按上面的实测数据估算：

| 开启的功能 | 每小时输入 token | 每小时费用 |
|---|---|---|
| 只开智能断句 | 约 60 万 | 约 0.025 美元 |
| 只开检查译文 | 约 26 万 | 约 0.011 美元 |
| 两个都开 | 约 86 万 | 约 0.036 美元 |

也就是说，两个都开时，每看 1 小时大约 0.04 美元，约 0.3 元人民币。

- 说话越密、停顿越多，请求越多；安静的片段不发请求。上表是直播闲聊的情况，其他内容可能不同。
- 选默认的 OpenCode Zen 服务时不需要 key，不向你收费；但它是非公开的免费接口，限额未知，随时可能限速或停用。
- 用 OpenRouter 时，按 OpenRouter 的计费规则从你的账户扣费。
- 以上价格是撰写时的标价，以服务方的最新价格为准。
